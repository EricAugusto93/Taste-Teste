# Store Assets - Taste App

Esta pasta contém todos os assets necessários para publicação nas lojas de aplicativos.

## Estrutura de Pastas

```
store_assets/
├── android/                 # Assets para Google Play Store
│   ├── icons/              # Ícones em diferentes tamanhos
│   ├── screenshots/        # Screenshots para diferentes dispositivos
│   ├── feature_graphic/    # Gráfico de destaque (1024x500)
│   └── descriptions/       # Textos e descrições
├── ios/                    # Assets para Apple App Store
│   ├── icons/              # Ícones em diferentes tamanhos
│   ├── screenshots/        # Screenshots para diferentes dispositivos
│   └── descriptions/       # Textos e descrições
└── shared/                 # Assets compartilhados
    ├── logos/              # Logos em diferentes formatos
    ├── mockups/            # Mockups para marketing
    └── press_kit/          # Kit de imprensa
```

## Requisitos de Assets

### Google Play Store
- **Ícone da aplicação**: 512x512 px (PNG)
- **Gráfico de destaque**: 1024x500 px (JPG ou PNG)
- **Screenshots**: Mínimo 2, máximo 8 por tipo de dispositivo
  - Telefone: 320-3840 px (qualquer lado)
  - Tablet 7": 320-3840 px
  - Tablet 10": 320-3840 px

### Apple App Store
- **Ícone da aplicação**: 1024x1024 px (PNG)
- **Screenshots**: Diferentes tamanhos para cada dispositivo
  - iPhone 6.7": 1290x2796 px
  - iPhone 6.5": 1242x2688 px
  - iPhone 5.5": 1242x2208 px
  - iPad Pro 12.9": 2048x2732 px
  - iPad Pro 11": 1668x2388 px
